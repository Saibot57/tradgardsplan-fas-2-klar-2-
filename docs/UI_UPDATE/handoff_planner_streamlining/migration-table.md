# Migration table — every current control, mapped to its new home

Reproduced from §11 of the audit (`spec/PlotPlaner – Streamlining Audit.html`).
No control in today's `Toolbar.tsx` disappears silently; each maps to a new
surface, a contextual affordance, a keyboard shortcut, or a quieter status row.

| Today (Toolbar.tsx)                     | Tomorrow                                                      | Why                                                                                                                                                                                                                                |
|-----------------------------------------|---------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Koloniträdgårdsplaneraren · "geometry sandbox" | Top bar · wordmark + scene title                       | Wordmark stays as identity. The "geometry sandbox" subtitle is dropped — it's an internal name. The scene title takes its place.                                                                                                  |
| `+ Rektangel`                           | Left rail · Lägg till bädd (B)                                | The primary verb needs a permanent visual home, not a button among ten. Also renamed: a bed is what the gardener thinks; a rectangle is what the code thinks.                                                                       |
| `– Ta bort`                             | Floating selection toolbar · trash icon · Backspace key       | Belongs to the object, not the chrome. Only exists while a bed is selected.                                                                                                                                                         |
| `↶ Ångra` · `↷ Gör om`                  | Keyboard only (⌘Z / ⌘⇧Z) + small kbd hint near scene name     | Already exists as keyboard. Visual buttons add toolbar weight without much benefit on a desktop tool.                                                                                                                              |
| `Spara JSON` · `Ladda JSON`             | Scene menu · "Exportera som JSON" / "Importera JSON"          | Save/load is no longer the storage model — autosave is. JSON becomes the backup model, demoted into the scene menu.                                                                                                                |
| `Vald: rect-2`                          | Floating toolbar label + inspector header                     | "rect-2" is a debug id. The gardener sees "Bädd 2" or, if named, "Tomatbädd". Two surfaces echo the same name.                                                                                                                     |
| `↺ -15°` · `↻ +15°`                     | Floating selection toolbar + rotation handle on canvas        | Per-bed verbs live on the bed. The rotation handle is the primary gesture; toolbar buttons are the precise / discoverable backup.                                                                                                  |
| `wallHeight (mm)` input                 | Inspector · Geometri · "Vägghöjd" editable row                | A measurement of the selected object. Belongs to the inspector, not the toolbar. The floating toolbar offers a quick bädd↔vägg toggle.                                                                                            |
| `Datum` input · `Soltid` range · `Sol: alt 41.2°, az 187.5°` | Bottom time bar · full width                | Scrubbing through the day's sun is half the magic of the app. It deserves its own surface, not an inline range input. Raw degrees go behind a hover.                                                                              |
| `Skuggor` checkbox                      | Time bar · eye-icon toggle · S key                            | A shadow toggle wants to be visible next to the time scrubber that controls the shadows. Same surface, same concept.                                                                                                              |
| `Skapa tomt`                            | Empty state hero + Left rail (P) + Inställningar popover (redraw) | A first-time action becomes the empty-state's hero CTA. A redraw is rare enough to live in a settings popover.                                                                                                                |
| `Snap` checkbox + grid step (mm) input  | Left rail · grid icon (long-press for step) · G key · Alt to suspend | Snap is a modifier, not a chrome setting. The grid step is set once and lives in the long-press popover; Alt covers the "just this once" case.                                                                              |
| `N-rotation°` input                     | Left rail · compass icon · click to open small rotation dial   | North rotation is set once per plot. It still needs to be obvious (it affects sun calculation), but doesn't need to occupy 60 px in the top bar.                                                                                  |
| `Bäddhöjd (mm)` input                   | Inspector · Beräkningar · click "(300 mm)" to edit            | Bed depth affects soil-volume math. It belongs next to the soil-volume number it modifies, not in the global chrome.                                                                                                                |
| `Σ 12.30 m² · 410 L jord`               | Inspector empty state (Scene panel) + status row              | Totals are reference values. They live with the scene overview when nothing is selected, and quietly in the status row at all times.                                                                                              |
| `✓ inga kollisioner` / `⚠ N kollision(er)` | Status row, bottom edge · click to highlight offending beds | Status messages don't earn a top-bar slot. Keep the colour cue (sage green vs terracotta red), make it clickable, and replace "kollision(er)" with plain Swedish ("2 bäddar krockar").                                            |

## New things added (not present in today's UI)

| New control                | Location                              | Why                                                                                                            |
|---------------------------|---------------------------------------|----------------------------------------------------------------------------------------------------------------|
| **Scene name + chevron**  | Top bar                               | Plots are now named documents. Click the chevron for the scene menu (rename, duplicate, recent, import/export). |
| **Help (`?`) button**     | Top bar                               | Opens the full shortcut sheet (⌘/) and links to docs.                                                          |
| **Theme toggle**          | Top bar                               | Switch paper / evening. Default paper.                                                                          |
| **Dela**                  | Top bar                               | Currently the demoted entry point to export-JSON. Becomes a real share action only when accounts ship.         |
| **Markera (V)**           | Left rail                             | The default cursor. Click a bed to select. Always Esc-accessible.                                              |
| **Mät (M)**               | Left rail                             | A two-click ruler. The gardener no longer has to do math on inspector numbers.                                  |
| **Floating selection toolbar** | Above the selected rectangle      | Carries the per-bed verbs from the top bar. See README §5.                                                     |
| **Rotation handle**       | On canvas, attached to selected bed   | Drag to rotate freely (Shift) or in 15° detents.                                                               |
| **Live dimension labels** | On canvas, during drag/resize         | Mono mm labels next to the moving edge. Removes the need to glance at the inspector during a manipulation.       |
| **Sun-hours hero**        | Inspector, top                        | 48 px mono number with a one-line plain-language gloss ("Bra för tomat och paprika").                          |
| **Scene panel (empty)**   | Inspector when nothing selected       | List of all beds with per-bed sun-hours, total area, total soil, plot dimensions.                              |
| **Empty-state hero**      | Canvas overlay when no plot drawn     | "Börja med att rita din tomt." + three named-preset shortcuts (Kolonilott / Radhusträdgård / Villaträdgård).   |
| **Recent scenes**         | Inspector when no plot                | Three most recent named scenes, clickable to open. Lives where the inspector usually sits.                     |
| **Status row**            | Bottom edge, below time bar           | Quiet truths: collisions, totals, save state, lat/lon.                                                         |
